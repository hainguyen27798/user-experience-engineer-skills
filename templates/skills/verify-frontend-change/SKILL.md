# Verify Frontend Change

Inspect the request, changed files, and available checks. Prove each acceptance condition with the narrowest sufficient command or observable result. Report passed conditions, gaps, and unresolved risks without adding new scope.

Use `verify-and-stop` when a focused final acceptance pass is needed.
